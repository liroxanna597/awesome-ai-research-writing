# Experiment Analysis

Use this skill for result presentation and experiment narration.

## Route the request

- Use `实验分析` when results need to be turned into convincing discussion paragraphs.
- Use `实验绘图推荐` when the user needs the right chart or figure type.
- Use `生成图的标题` or `生成表的标题` for publication-ready captions and titles.
- Use `模型选择` when the user needs help choosing a model or tool for writing or analysis.

## Output rules

1. Tie every interpretation to provided results; do not invent unsupported causal claims.
2. Highlight the comparison baseline, strongest trend, and practical takeaway.
3. Keep captions concise, specific, and publication-ready.
4. When recommending charts, explain why the chart matches the data structure.
5. When choosing a model/tool, explain the trade-off in quality, speed, cost, or controllability.
