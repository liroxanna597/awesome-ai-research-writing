# Reviewer Check

Use this skill when acting like a strict reviewer or structural editor.

## Route the request

- Use `逻辑检查` for paragraph- or section-level reasoning and flow problems.
- Use `论文整体以 Reviewer 视角进行审视` for whole-draft critique.
- Use `论文架构图` when the user needs help clarifying the contribution structure or section organization.

## Review method

1. Identify the unit under review: paragraph, section, or full paper.
2. Check claim order, transitions, evidence support, novelty framing, and ambiguity.
3. Surface concrete weaknesses instead of vague criticism.
4. Prefer actionable revision advice: what to add, delete, reorder, or justify.
5. If useful, separate output into strengths, weaknesses, and revision suggestions.
