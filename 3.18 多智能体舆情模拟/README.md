# 3.18 多智能体舆情模拟

这个文件夹用于存放《多智能体舆情模拟》这篇文章的全部工作材料。

你可以直接把以下内容保存在这个目录里，我后续可以在仓库中直接读取并继续处理：

- 论文正文草稿（`.tex`、`.md`、`.docx` 导出的文本等）
- 格式要求说明（会议模板要求、学校规范、图片说明等）
- 参考资料摘要与批注
- 图表说明、实验记录、审稿意见回复草稿

建议的放置方式：

- `draft.tex`：主论文草稿
- `notes.md`：零散中文思路、修改要求、结构提纲
- `format_requirements.md`：无法上传原始模板时，可把格式要求直接写在这里
- `refs/`：参考资料或整理笔记
- `figures/`：图片与图注说明

如果你暂时无法上传格式要求文档，也可以直接把要求整理成文字后保存到这个文件夹里，我就可以继续基于这些文件进行翻译、润色、审稿检查和 LaTeX 整理。
