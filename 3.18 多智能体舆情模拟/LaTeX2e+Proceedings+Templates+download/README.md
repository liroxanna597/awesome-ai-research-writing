# LNCS Template Workspace

This folder is the working manuscript location corresponding to the LNCS-style template path you pointed to.

## Expected template assets

According to the GitHub folder you referenced, this directory should contain at least the following template files when the full package is available:

- `llncs.cls`
- `splncs04.bst`
- `samplepaper.tex`
- `readme.txt`
- `history.txt`
- `llncsdoc.pdf`
- `fig1.eps`

## Current manuscript files

- `paper.tex`: the paper source adapted to the LNCS proceedings structure
- `sections/introduction.tex`: the current introduction section
- `refs/references.bib`: placeholder bibliography entries

If you sync the full template package into this directory, the manuscript can be compiled from `paper.tex`.
